# S05 — Critical Siege

## Purpose
Heighten urgency when the Core is near authoritative defeat without replacing the game with overlays.

## Trigger
Core Integrity <= configured critical threshold.

## World changes
Prefer world-space cues:
- Core becomes more exposed;
- emissive pulse increases;
- subtle sparks/smoke;
- more obvious damaged silhouette;
- optional low-frequency warning pulse in shield/Core effects.

## DOM changes
- compact critical Core treatment;
- optional one-line warning such as `CORE CRITICAL`;
- Attack/Defend remain dominant.

Do not add:
- full-screen red warning;
- giant modal;
- extra statistics.

## Exit
- S03 if threshold no longer applies through valid shield/protection state while Core itself remains irreversible;
- S24 on Core destruction.
