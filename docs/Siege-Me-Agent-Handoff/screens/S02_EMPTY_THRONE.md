# S02 — Empty Throne

## Purpose
Seed the first/current reign when no valid ruler exists.

## Entry
Authoritative world reports no active ruler/reign.

## 3D composition
Use the actual procedural fortress/world, not a separate palace asset.
Fortress may appear:
- clean/unclaimed;
- neutral banners;
- dormant Core;
- no ruler crest;
- no attack damage.

Camera should match the same canonical family used by S03 so transition to a claimed throne feels continuous.

## DOM components
- Siege Me mark
- 'The throne is empty'
- concise one-sentence explanation
- Claim the throne CTA
- claim price if claim is paid
- How it works
- optional History

## Claim action
Use the claim/coronation rules in the full specification. Do not invent a separate ownership model.

## Must not show
- fake ruler
- Attack CTA against nobody
- Defend CTA
- siege queue
- damage HUD
