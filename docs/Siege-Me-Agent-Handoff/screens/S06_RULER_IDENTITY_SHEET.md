# S06 — Ruler Identity Sheet

## Purpose
Provide public identity detail without permanently occupying the main game surface.

## Presentation
Bottom sheet on mobile; compact side/bottom sheet on desktop.
Game world remains visible behind it.

## Fields
- logo/avatar
- display name
- identity type
- verified badge if applicable
- visible destination domain
- one-line message
- constrained CTA
- optional social handle
- reign duration
- concise reign stats

## CTA safety
Destination domain remains visible.
No arbitrary HTML, embedded forms, iframe or custom script.

## Actions
- open destination URL
- close
- share current reign
- view reign history/details

## Must not become
A mini landing page or advertiser-controlled microsite.
